# Gremlin Game

A 2.5D action RPG featuring fast combat, supernatural powers,
multiple personalities, and an interconnected world.

## Engine
Godot Engine

## Language
C++ (GDExtension)

## Current Status
Pre-production

## Core Stats
- HP
- XP
- STR
- AGL
- DEF
- DEX
- AUR
- END
- EN
- WP
- CHAOS

## Core Mechanics
- Personality switching
- Ability unlocking through World Power (WP)
- Chaos regeneration through combat and ability mixing
